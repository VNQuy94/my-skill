# Profile `nd30` — Vietnamese administrative documents

Layout rules from **Appendix I of Decree 30/2020/ND-CP** (Nghị định 30/2020/NĐ-CP, 05/03/2020) on the format of administrative documents. The values below were read from the text of Appendix I. For a document that will actually be issued, compare the result with the official sample forms (Mục IV, Phần I of the appendix), because positions are defined there by numbered boxes.

## Page and text

| Element | Rule | In the profile |
|---|---|---|
| Paper | A4 (210 × 297 mm), portrait | `page.paper` |
| Margins | top/bottom 20–25 mm, left 30–35 mm, right 15–20 mm | 20 / 20 / 30 / 15 |
| Font | Times New Roman, Unicode TCVN 6909:2001, **black** | Times New Roman → Liberation Serif fallback (same metrics) |
| Body text | lower case, justified, upright, size 13–14 | 14 pt, justified |
| First-line indent | 1 cm or 1.27 cm | 12.7 mm |
| Paragraph spacing | at least 6 pt | 6 pt |
| Line spacing | from single up to 1.5 lines | 1.2 |
| Page numbers | Arabic numerals, size 13–14, centred in the top margin, **not shown on page 1** | `top-center`, first page hidden |

## Header block (`nd30-header`, Typst only)

| Element | Rule |
|---|---|
| Quốc hiệu "CỘNG HÒA XÃ HỘI CHỦ NGHĨA VIỆT NAM" | upper case, 12–13, upright, bold, top right |
| Tiêu ngữ "Độc lập - Tự do - Hạnh phúc" | 13–14, upright, bold, centred under the Quốc hiệu, hyphens between phrases, a solid line underneath as long as the text |
| Tên cơ quan chủ quản (parent body) | upper case, 12–13, upright; common phrases may be abbreviated (useful when the name wraps) |
| Tên cơ quan ban hành (issuing body) | upper case, 12–13, upright, bold, centred under the parent body, solid line underneath 1/3–1/2 of its length |
| Số, ký hiệu | "Số" lower case, size 13; centred under the issuing body |
| Địa danh, ngày tháng năm | lower case, 13–14, **italic**, centred under the motto |
| Tên loại văn bản (e.g. THÔNG BÁO) | upper case, 13–14, upright, bold, centred |
| Trích yếu (subject) | lower case, 13–14, upright, bold, under the type, with a line 1/3–1/2 of its length underneath |
| Công văn | subject goes after "V/v" under the number instead (size 12–13); the helper does not handle this variant |

## Structure of the body

- Căn cứ (legal bases): italic, 13–14, under the subject; each on its own line ending with ";", the last one ending with ".".
- Phần / Chương: the word and Roman numeral on their own line, centred, bold; the title below in upper case, bold.
- Mục / Tiểu mục: same, with Arabic numerals.
- Điều: "Điều 1." bold, indented like a paragraph.
- Khoản: "1." upright; points: "a)", "b)"… using the Vietnamese alphabet.
- End the body with "./." where customary.

## Signature and recipients (`nd30-signature`, Typst only)

- Authority (e.g. "TM. ỦY BAN NHÂN DÂN", "KT. GIÁM ĐỐC") and title: upper case, bold, centred on the right.
- Full name: lower case with capitals, bold, below the signature space.
- "Nơi nhận:" italic bold 12 on the left; each recipient line size 11, starting with "- " and ending with ";", the last one "- Lưu: VT, …".

## Limits

- Colors: black only. Tables use thin black rules; callouts become a thin black box.
- The header and signature helpers exist only for Typst/PDF. For DOCX, build the header as a borderless two-column table with the same sizes, or ask the user for their organisation's .dotx template (better: an official template).
- `lint.wall_of_text` is off for this profile: administrative documents are prose by nature.
